# 0.2.0 原生桌面版

第二版由两部分组成：Harness 插件（注册 `iab_*` 工具）和 Electron 桌面启动器（显示真实网页）。现有 Tauri 桌面程序不需要修改；本启动器是独立的替代前端，连接你已经启动的本机 Harness 服务。

## 安装与启动

1. 在运行 Harness 的同一个环境中安装：

   ```powershell
   dsh plugin --profile web add dsh-better-sidebar@0.19.1
   dsh plugin --profile web add "插件包实际路径\dsh-inapp-browser-0.2.1.tgz"
   ```

   已有兼容 Better Sidebar 时跳过第一条。重启 Harness 服务；不需要卸载旧的 `browser_*` 插件，但本任务请使用 `iab_*`。

2. 启动本机 Harness，通常运行 `dsh web`。保留它的终端进程。先不要在普通网页中打开浏览器会话。
3. 解压原生桌面包，双击 `Start-Browser.cmd`。默认连接 `http://127.0.0.1:3080`。其他端口：

   ```powershell
   .\Start-Browser.cmd --harness=http://127.0.0.1:3081
   ```

4. 在新桌面窗口打开聊天，从 Better Sidebar 的「+」打开「浏览器」。网址、搜索和页面直接输入都在这个窗口完成。

只下载源码时，在 `desktop` 目录执行 `npm install` 后 `npm start -- --harness=http://127.0.0.1:3080`。原生桌面包已经带运行时，不需要这一步。

0.2.1 只需升级插件，0.2.0 启动器仍兼容。新版默认必应，工具栏“更多”展开搜索设置；底部“原生显示”表示真正的桌面视图，“兼容显示”表示画面传输。

## 人与 AI 共用

> 使用 iab_open 打开 https://www.baidu.com，用 iab_snapshot 查看页面，然后搜索“DeepSeek”。使用浏览器的 iab_* 工具。

模型支持图片时再调用 `iab_screenshot`。截图按需生成，正常浏览不传输截图、JPEG 或视频。页面大小跟随侧栏与窗口变化；鼠标、滚轮、选择复制文字、中文输入直接由 Chromium 处理。

人工操作不会自动暂停 AI。双方同时操作可能冲突，需要时点「暂停 AI」。该按钮立即拒绝后续浏览器操作，并通过 Harness agent.cancel 请求终止当前任务；若宿主无法提供取消接口，界面会明确提示仍需点聊天停止按钮。已经发送到网页的动作不能撤回。点「允许 AI」只重新允许新操作，不会恢复已终止的任务；需要再发一条指令。

## 与第一版的差异

- 原生端使用 Electron WebContentsView，AI 通过私有本机管道和 CDP 操作同一视图。没有对公网开放调试端口。
- 普通 Web 端仍保留第一版画面传输作为兼容方案，不应把它与原生端的流畅度混为一谈。
- 原生资料在 `DSH_IAB_DATA_DIR` 或默认 `~/.dsh/storages/dsh-inapp-browser/profiles-native/` 下，按聊天隔离。不会读取或迁移你的 Edge 日常资料，也不自动迁移第一版的登录状态。
- 关闭侧栏只隐藏页面，关闭浏览器会话释放该聊天视图，退出桌面端关闭其原生浏览器会话。Harness 服务继续运行。
- 仅支持本机 HTTP Harness 地址，一个 Harness 实例同时配对一个原生桌面端。

## 边界与故障

- 「已有桌面端连接」：关闭旧启动器；若旧进程异常退出，重启 Harness 清除配对后重试。
- 「请先关闭已打开的浏览器会话」：在 Web 端关闭第一版会话或重启 Harness，然后再开桌面启动器。
- 页面禁止的网站、验证码、登录风控仍由网站决定。原生视图并非免验证浏览器。
- 本版不自动授予摄像头、麦克风等设备权限；扩展、密码管理器、下载管理器和复杂登录弹窗尚未作为完整浏览器产品验收。
- 新窗口链接会作为受控标签打开；依赖 popup/opener 语义的 OAuth 流程需要另行适配。
- 原生视图覆盖在侧栏的网页区域，第三方插件若在该区域弹出浮层可能需要适配；普通地址栏、暂停按钮和聊天区不被覆盖。
- 自动测试能验证工具和视图联通，不能替代你的实际 Harness、模型和目标网站验收。详见 VALIDATION.md。
